# Development log - 2026-05

## 2026-05-31 - Theme maintenance became contract-driven

### Result

- Introduced a single install manifest, palette drift guard, CI checks, install
  and uninstall round-trip tests, and an independent iTerm2 palette
  cross-check.

### Why / context

- Theme files and installer branches can silently diverge unless supported
  tools, destinations, colors, and round-trip behavior have executable owners.

### Evidence

- PR #1 established the manifest and validation entrypoint; PR #2 added
  temporary-home round trips and numeric iTerm2 color verification.
